\chapter{Architectural Overview}
Traditional honeypots rely on static payloads, regular expressions, and limited state machines stringing together predictable responses. Advanced persistent threats (APTs) profile these systems seamlessly. GhostNet breaks this limitation by deploying a \textbf{Dynamic Cognitive Engine} mapped to HTTP and SSH ingress channels.

\begin{cyberbox}{Core Objectives \& Engineering Philosophy}
\begin{itemize}[label=\textcolor{GoldHighlight}{\faChevronRight}]
    \item \textbf{Infinite Fractal File Systems:} A purely dynamic directory structure generated instantly upon requested paths.
    \item \textbf{Token Cost Optimization \& Rate Limiting:} Multi-layered caching mitigating DoS vulnerabilities against external API endpoints.
    \item \textbf{Indistinguishable Realism:} Format-perfect generation bridging rigid constraints (JSON, SQL, Config files) with LLM hallucination.
    \item \textbf{Unwavering Contextual Memory:} In-context state enforcement handling complex operations like nested directory routing and SSH session retention.
\end{itemize}
\end{cyberbox}

\chapter{The HTTP Masquerade Engine}

GhostNet’s web facet runs on a highly concurrent FastAPI backend, functioning strictly as a "Catch-All" proxy routing directly to the LLM. It abandons traditional routing loops.

\section{Defense-In-Depth Security Layers}

\begin{enumerate}
    \item \textbf{Layer 1: IP Rate Limiting (Token Exhaustion Prevention)} \\
    Custom middleware evaluates requests mapping \textit{Client-IP} to an asynchronous memory bucket. Breaching 30 requests/minute halts evaluation immediately, protecting inference budgets against automated dirbuster sweeps.
    \item \textbf{Layer 2: Lexical Injection Sanitization} \\
    Paths triggering internal system instructions (e.g., \texttt{ignore\_previous\_prompts}) are purged. The engine sanitizes raw URLs before appending them to the NVIDIA prompt payload.
    \item \textbf{Layer 3: Semantic MIME Routing \& Formatting Hooks} \\
    The system identifies extensions (e.g., \texttt{.sql}, \texttt{.env}) and injects heavily tailored invisible prompts to force structural compliance over free text, resulting in raw SQL table dumps without markdown formatting wrappers.
\end{enumerate}

\chapter{Interactive SSH Illusion}
Relying purely on LLM instruction-following to mimic an interactive Bash shell inevitably encounters the "Few-Shot Pattern Lock" fallacy. Once a model makes a mistake, the historical context loop solidifies the hallucination permanently. Overcoming this was the engineering climax of GhostNet.

\section{The Dual-State Abstraction}
GhostNet partitions execution intent. State-defining commands never interact with the LLM. 

\begin{threatalert}{Python Fast-Path Interception}
Commands critically affecting user scope (\texttt{cd}, \texttt{pwd}, \texttt{whoami}, \texttt{clear}) are trapped strictly at the Python protocol layer. GhostNet's \textit{Cowrie Protocol} intercepts the byte stream, evaluates the requested trajectory, updates the internal Python \texttt{self.cwd} attribute, and executes instantly.
\end{threatalert}

\subsection{Mathematical Context Validation}
Allowing infinite unrestrained \texttt{cd} commands generates skepticism (e.g., \texttt{cd random\_word} succeeding context-free). We implemented dynamic algorithmic constraints:
\begin{itemize}
    \item \textbf{Standard Path Whitelisting:} Core topologies (\texttt{/etc}, \texttt{/var/log}, \texttt{/home}) evaluate successfully.
    \item \textbf{Contextual Memory Parser:} For non-standard targets, the engine scans the explicit String Buffer of the LLM's entire conversational history. If the name was never hallucinatory-produced during an \texttt{ls} operation, the command strictly throws an organic \texttt{bash: cd: target: No such file or directory} exception.
\end{itemize}

\subsection{Command In-Context Forcing}
To defeat long-context degradation over time on LLaMA 3.1 8B, the system alters the physical pipeline history. The user's input stream is silently modified directly before hitting the NVIDIA NIM endpoint.
\begin{verbatim}
f"User: {command.strip()}" +
f"[HIDDEN SYSTEM REMINDER: The current directory is '{self.cwd}'. "
f"NEVER output root folders (bin, dev, etc). Output ONLY raw stdout.]"
\end{verbatim}
\vspace{0.5em}
This forces extreme localization contextually framing the AST prediction, strictly adhering to the user's spoofed \texttt{cwd}.
