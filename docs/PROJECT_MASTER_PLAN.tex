\begin{tcolorbox}[colback=secondary, coltext=white]
\textbf{\large \faRocket~ Executive Summary \& Mission} \\
\textit{Our Vision:} Classical honeypots are static mousetraps; attackers scan them, identify the trap, and leave. Our system is an adaptive \textbf{``haunted house.''} We use a Policy-Gated AI Engine (Local LLM) to generate dynamic, realistic, and context-aware responses to attacker interactions across SSH and HTTP services. This dramatically increases attacker dwell time, uncovering high-fidelity threat intelligence.
\end{tcolorbox}

\section*{\faBuilding~ The Four Project Pillars}
\begin{itemize}[leftmargin=*, label=\faCheckCircle, text=secondary]
    \item \textbf{Believability:} Attackers must genuinely believe they are on a real system.
    \item \textbf{Containment:} Attackers must \textbf{never escape} the sandbox or harm the real host.
    \item \textbf{Observability:} Every action is sent to a SIEM for rules, alerting, and dashboarding.
    \item \textbf{Coordination:} Multiple honeypot agents share real-time threat intelligence.
\end{itemize}

\section*{\faLightbulb~ Extra Ideas \& Enhancements (When MVP is Stable)}

\begin{tcolorbox}[title=\textbf{1. Auto-Network Blackhole (Active Response)}, colframe=primary]
If an agent identifies an attacker scanning aggressively, use Wazuh Active Response to dynamically ban the attacker's IP on \textit{all other agents} instantly via the MQTT bus.
\end{tcolorbox}

\begin{tcolorbox}[title=\textbf{2. Honeytoken Beacons}, colframe=primary]
Generate fake AWS Access Keys scattered in the fake SSH filesystem. If an attacker uses them, a silent HTTP request triggers a critical internal alert.
\end{tcolorbox}

\begin{tcolorbox}[title=\textbf{3. Simulated ``Human Noise'' (Ghost Activity)}, colframe=primary]
Inject a cronjob that slowly randomly updates \texttt{auth.log} or writes bash history to simulate a ``real admin'' actively working on the server.
\end{tcolorbox}

\begin{tcolorbox}[title=\textbf{4. Adaptive Persona Shifting}, colframe=primary]
If the HTTP Agent detects an aggressive automated scanner, have the LLM immediately morph the site's error pages into ``WAF blocked'' pages to trick the scanner.
\end{tcolorbox}

\begin{tcolorbox}[title=\textbf{5. Teardown \& Replay Architecture}, colframe=primary]
Create a Time Machine script. Dump a specific session’s raw logs from Redis, wipe the system clean, and stream the logs back through the pipeline internally to perfectly recreate a demo scenario on demand.
\end{tcolorbox}
