\section{Protection \& Monitoring: Scaling Responsibly}
Deploying an LLM in a public environment is risky. GhostNet implements a three-tier protection strategy:

\begin{enumerate}
    \item \textbf{Financial Safety (Rate Limiting):} Intelligent memory-buckets block automated scanners from exhausting API tokens. We prioritize human detection.
    \item \textbf{Injection Guard (Prompt Sanitization):} Incoming paths and commands are scanned for "LLM jailbreak" attempts, ensuring the model stays in its role.
    \item \textbf{Zero-Maintenance State Persistence:} The Python core manages the directory structure (`cd`, `pwd`), ensuring 100\% consistency while the model handles file content.
\end{enumerate}
